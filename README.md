# Dominael

Loja simples de produtos digitais integrada à InfinitePay e Supabase.

- Compra sem cadastro na Dominael
- Pix e cartão via InfinitePay
- Painel administrativo exclusivo
- Produtos com entrega por download privado ou link externo
- Senha fixa definida por produto para acesso posterior
- Arquivos protegidos no Supabase Storage
